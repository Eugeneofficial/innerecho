# FoodSync — Совместный контроль питания

## Что это?
FoodSync — приложение для совместного контроля питания с партнёром. Ведите общий дневник питания, видите прогресс друг друга, поддерживайте и мотивируйте.

## Возможности

### Основные
- 👥 **Два профиля** — индивидуальные цели для каждого
- ⚡ **Быстрый ввод** — добавить приём пищи за 10 секунд
- 📱 **Общая лента** — видите что ел партнёр
- ❤️ **Реакции** — поддержка через эмодзи (👍/❤️/🔥)
- 🎯 **Цели** — калории, белки, жиры, углеводы
- 📊 **Статистика** — графики за день/неделю/месяц
- 💾 **Шаблоны** — сохраняйте частые блюда

### Дополнительно
- 📸 Фото еды
- 💧 Водный баланс
- ⚖️ Трекинг веса
- 📥 Экспорт данных
- 🌙 Тёмная/светлая тема

## Быстрый старт

### 1. Установка зависимостей
```bash
# Backend
cd server
npm install

# Frontend
cd ../client
npm install
```

### 2. Запуск
```bash
# Запустить всё одной командой
npm start
```

Или запустить отдельно:
```bash
# Backend (порт 3001)
cd server
npm start

# Frontend (порт 3000)
cd client
npm start
```

### 3. Открыть
Перейди на http://localhost:3000

## API

### Пользователи
- `GET /api/users` — список пользователей
- `POST /api/users` — создать пользователя
- `PUT /api/users/:id` — обновить профиль

### Приёмы пищи
- `GET /api/meals` — все приёмы пищи
- `GET /api/meals/:userId` — приёмы конкретного пользователя
- `POST /api/meals` — добавить приём пищи
- `PUT /api/meals/:id` — редактировать
- `DELETE /api/meals/:id` — удалить

### Шаблоны
- `GET /api/templates/:userId` — шаблоны пользователя
- `POST /api/templates` — создать шаблон
- `DELETE /api/templates/:id` — удалить шаблон

### Статистика
- `GET /api/stats/:userId?period=day|week|month` — статистика

## Технологии
- **Frontend:** React 18
- **Backend:** Node.js + Express
- **База данных:** SQLite
- **Стили:** CSS (чистый)

## Приватность
Все данные хранятся локально на твоём компьютере. Никаких облаков, никаких трекингов.
