## 🚀 Как запустить

### Вариант 1: Автоматически (Windows)
```bash
start.bat
```

### Вариант 2: Вручную
```bash
# Terminal 1 - Backend (порт 3005)
cd server
npm install
npm start

# Terminal 2 - Frontend (порт 3000)
cd client
npm install
npm start
```

Откройте: **http://localhost:3000**

## 🎨 Особенности

### Поиск
- Начните вводить название блюда
- Появятся подсказки
- Используйте фильтры для точного поиска
- История сохраняется автоматически

### VK-дизайн
- Левый сайдбар: навигация
- Центр: лента приёмов пищи
- Правый сайдбар: статистика и пользователи
- На мобильных: нижняя навигация

### Горячие клавиши
- `N` - добавить приём пищи
- `1` - лента
- `2` - статистика
- `3` - профиль
- `4` - события
- `D` - день
- `W` - неделя
- `M` - месяц

## 📝 Технические детали

**Frontend:**
- React 18
- CSS Variables (темы)
- Service Worker API
- IndexedDB

**Backend:**
- Node.js + Express
- SQLite (better-sqlite3)
- Multer (загрузка фото)

**API Endpoints:**
- `/api/meals` - с фильтрами и поиском
- `/api/search/autocomplete` - автодополнение
- `/api/search/popular` - популярные блюда
- `/api/search/recent` - недавние блюда
- `/api/users` - пользователи
- `/api/stats` - статистика
- `/api/templates` - шаблоны
- `/api/events` - события
- `/api/achievements` - достижения
